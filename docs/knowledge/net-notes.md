## 协议对比（TCP / UDP / KCP）

- **TCP**：追求绝对可靠和稳定，速度是次要的（下载文件、网页浏览）
- **UDP**：追求极速，可靠性交给应用层处理（视频流、DNS 查询、VoIP）
- **KCP**：在 UDP 基础上，自己实现了一套为实时性优化的可靠传输机制，目标是比 TCP 延迟更低（实时游戏、语音通话）

所以「基于 UDP 实现 KCP」意思是：在 UDP 这个快速但不可靠的通道上，用 KCP 算法库实现可靠传输——既能享受 UDP 的速度，又能获得类似 TCP 的可靠性，并且延迟更低。

注意：KCP 不是 UDP，也不是通信协议，而是基于 UDP 的算法实现。

### 粘包处理

使用数据头和数据体：

- 数据头为 int 4 字节，存储 body 的 byte 数组长度
- 数据体为各种数据

处理方法：无论接收到什么，始终按照 `byte[4] + byte[x]` 进行接收。如果头没接完，下个包体的前 `4-n` 位组合成头；如果身体没接完，只有 m，下个包体的前 `x-m` 组成身体。哪怕一个包体只存在 `byte[1]`，都会变成头或者身体一部分。
