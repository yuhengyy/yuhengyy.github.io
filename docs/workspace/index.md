# 博客与代码

本站记录技术学习、项目实践和经验总结。文章与代码分别维护，通过来源链接相互关联。

| 内容 | 位置 |
|---|---|
| 公开文章、导航与站点资源 | 本博客 |
| 可运行的 C# 或 Unity 工程 | 对应代码仓库 |
| 文章对应的源码入口 | [代码来源](repos.md) |

阅读文章不需要本机工程；克隆和构建本博客也不依赖其他项目。技术笔记可对应一个代码仓、多个仓库或单纯的知识主题。
